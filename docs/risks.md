# Project Risks

## Data Availability

Obtaining high-quality and up-to-date flight price data may be difficult due to API limitations or licensing restrictions.

## Model Accuracy

Flight prices are influenced by many external factors such as holidays, demand, and airline policies, which may reduce prediction accuracy.

## API Dependency

The platform depends on third-party flight APIs. Service outages or rate limits may affect functionality.

## Scalability

Large numbers of users or prediction requests may increase infrastructure costs and response times.

## Security

Improper handling of authentication or sensitive user information could expose security vulnerabilities.

## Project Complexity

The project combines AI, machine learning, data science, backend development, frontend development, and deployment, making it important to prioritize core features and follow an incremental development approach.
