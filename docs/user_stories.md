# User Stories

## Authentication

1. As a guest, I want to register so that I can use personalized features.

2. As a guest, I want to verify my email so that my account is secure.

3. As a user, I want to log in securely so that my personal data remains protected.

4. As a user, I want to reset my password so that I can recover my account.

5. As a user, I want to update my profile so that my preferences remain current.

---

## Flight Search

6. As a user, I want to search flights by origin, destination, and travel date so that I can find available flights.

7. As a user, I want to search round-trip flights so that I can plan my return journey.

8. As a user, I want to filter flights by airline so that I can choose preferred airlines.

9. As a user, I want to filter flights by stops so that I can avoid unnecessary layovers.

10. As a user, I want to sort flights by price, duration, or departure time so that I can compare options quickly.

11. As a user, I want airport autocomplete so that I can enter airports faster.

---

## AI Price Prediction

12. As a user, I want predicted future prices so that I know whether to book now or wait.

13. As a user, I want to view prediction confidence so that I understand the reliability of the prediction.

---

## Recommendation System

14. As a user, I want recommendations based on my travel preferences so that I spend less time comparing flights.

15. As a user, I want recommendations within my budget so that I avoid expensive options.

16. As a user, I want recommendations based on previous searches so that results become more personalized over time.

---

## Dashboard

17. As a user, I want to view my search history so that I can revisit previous searches.

18. As a user, I want to view my favorite flights so that I can easily compare saved options.

19. As a user, I want to see travel statistics so that I can better understand my travel habits.

20. As a user, I want to view previous predictions so that I can compare predicted and actual prices.

---

## Feedback

21. As a user, I want to submit feedback so that I can help improve the platform.

---

## Administration

22. As an admin, I want to monitor active users so that I understand platform usage.

23. As an admin, I want to monitor prediction accuracy so that I can evaluate model performance.

24. As an admin, I want to retrain machine learning models so that predictions remain accurate.

25. As an admin, I want to monitor API usage so that I can detect abnormal activity.

26. As an admin, I want to manage user accounts so that the platform remains secure.
